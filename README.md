# Indian River Launchpad

Launch IRC provides business launch guidance, local resources, events, and personalized checklists for Indian River County entrepreneurs.

## Local Development

1. Install dependencies with `yarn install`.
2. Start the development server with `yarn start`.
3. Build for production with `yarn build`.

Application records and accounts are stored in the browser's local storage. They are specific to the current browser and device; clear site data to reset them.
